#  OverTheWire: Bandit (Level 20+) - Walkthrough & Security Notes

This repository contains my technical notes, commands, and logic while solving levels 20 through 34 of the [OverTheWire: Bandit](https://overthewire.org/wargames/bandit/) wargame.

> **Note:** Levels 0–19 were completed prior to establishing this public documentation log. Focus in this repository is placed on intermediate/advanced Linux security concepts (Level 20+).

## **Level 20 - 21**
**OBJECTIVE:-**  Make a connection with the setuid binary through any localhost port and pass the password of the current level.

**KEY COMMAND:-** `echo "password" | nc -l -p <port> &`
 
**CONCEPT:-** Create a backgroud listening port using Netcat (`nc -l`) followed by (`&`) which makes it run in the background and then just pass the port to the setuid binary using (`./suconnect <port>`) so that it could establish the connection and verify the password.

## **Level 21 - 22**
**OBJECTIVE:-**  Find the password by inspecting cron jobs that are schduled system tasks.

**KEY COMMAND:-** `cat /usr/bin/cronjob_bandit22.sh`
 
**CONCEPT:-** Inspect a cronjob structure (`cat /etc/cron.d`) to find an automatically generating shell script (`/usr/bin/cronjob_bandit22.sh`) that is redirecting the password to another directory (`/tmp...`) and then concatenate the file to get the next password. 

## **Level 22 - 23**
**OBJECTIVE:-**  Find the temporary password file generated by `bandit23`'s cronjob.

**KEY COMMAND:-** `echo "I am user bandit23" | md5sum | cut -d ' ' -f 1`
 
**CONCEPT:-** `/usr/bin/cronjob_bandit23.sh` hides its output file in `/tmp...` using an MD5 hashing, concatenate the script and read it manually, then predict the output file name and get the password.
